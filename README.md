# SSH-Honeypot-using-Python

Honeypot is a cybersecurity mechanism that acts as a decoy to attract and trap cyber attackers, diverting them from the real systems and allowing security teams to study their methods and gather threat intelligence.![maxresdefault](https://github.com/user-attachments/assets/e36f68c9-bf55-4d16-ac03-338904789c3c)

🚀 Project Overview
This project implements a basic SSH honeypot in Python, inspired by 0xdf’s video tutorial. It listens for incoming SSH connections, simulates a login prompt, and logs the attacker’s inputs—such as username, password, and source IP address.

This is a research/educational honeypot, not intended to provide real SSH access.

🔍 Key Features:

✅ Python-based fake SSH server

✅ Listens for unauthorized SSH login attempts

✅ Logs attacker credentials (username, password)

✅ Captures IP addresses and timestamps

✅ Lightweight and easy to run on any Linux system

✅ Good for threat intel, training, or demo use
